# Changelog

## 0.1.0 — Initial Phase 1 release

- Add a versioned UTF-8 payload format and PNG RGB/RGBA LSB encoding/decoding.
- Add capacity checks, image safety limits, a command-line interface, and basic inspection.
- Add initial tests, installation instructions, and security documentation.
- Encryption, binary-file payloads, advanced forensics, GUI, and CI are not part of this release.
